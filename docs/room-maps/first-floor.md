# First Floor Room Map

Use this document alongside the floorplan image to describe room names, switch locations, Pico placements, and lighting zones.

## Rooms

### Kitchen

- Primary Govee lighting zone for task lighting.
- Optional accent zone for cabinet or ambient lighting.
- Pico expected near main entry or island path.

### Foyer

- Simple arrival/departure lighting zone.
- Candidate room for an "all off" shortcut depending on layout.

### Living Room

- Likely to need layered scenes such as daytime, evening, and movie mode.
- Consider one button for scene cycling if the Pico layout supports it.

### Hallway

- Transitional lighting between foyer and main living spaces.
- Good candidate for time-aware brightness levels.
